# Vendored Geist (latin)

Latin-subset WOFF2 files used by `src/app/layout.tsx` through `next/font/local`.

These files are the production source of truth. Do not load Geist from
`next/dist/next-devtools/server/font` — that path is a Next.js overlay
dev asset, not a production font contract.

- `geist-latin.woff2` — body sans (preloaded)
- `geist-mono-latin.woff2` — mono (not preloaded)
