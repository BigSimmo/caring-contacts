- Physical iPhone Safari: unrun; separate acceptance work.
- Installed PWA on a physical device: unrun; separate acceptance work.
- Broad `verify:ui`: deliberately unrun when final diff inspection confirms the implementation remains mockup-scoped and does not change a shared production UI foundation.
- Live providers, production data, Supabase, RAG, analytics and messaging delivery: intentionally absent and unrun.
